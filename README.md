# 🎓 Student Performance Prediction using Machine Learning

## 📌 Project Overview

Student Performance Prediction is a Machine Learning project that predicts a student's expected final exam score based on their study hours, attendance percentage, and previous exam score.

The project uses Python and Linear Regression to learn patterns from student academic data and predict the expected performance of a new student.

## 🔴 Problem Statement

It can be difficult for teachers and educational institutions to identify a student's expected academic performance at an early stage.

This project aims to predict a student's final exam score using important academic factors such as study hours, attendance, and previous exam performance.

## 🟢 Solution

A Machine Learning model is trained using student academic data.

The model takes the following inputs:

- Study hours per day
- Attendance percentage
- Previous exam score

Based on these inputs, the model predicts the student's expected final exam score and provides a performance category.

## 🛠️ Technologies Used

- Python
- NumPy
- Scikit-learn
- Machine Learning
- Linear Regression

## ⚙️ How the Project Works

1. Collect student academic data.
2. Use study hours, attendance, and previous score as input features.
3. Train a Linear Regression model.
4. Enter details of a new student.
5. Predict the expected final exam score.
6. Display the student's performance category.
